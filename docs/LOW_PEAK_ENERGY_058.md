# 8-degree walking: low-amplitude positive energy residual

Run 175997260 used version 1.0.57. In 5–20 seconds the positive/negative peaks averaged 4.84/4.18 degrees; foot marker cycle ranges were 18.50/1.64 px (camera relative). Phase-matched pre-input RPM averaged +47/+304. These do not by themselves establish foot-ground travel, yaw, or actuator causality. The low-speed 10–25 ms branch did run, but the negative peak decreased later in the record. Foot ABA remained at phase 0 because the model inputs were extrapolated/saturated. The gyroscope heading output was disabled; no yaw feedback was present.

The positive branch-5 model remained at 400mA/80ms and underpredicted its measured arrival potential: 37 matched sub-6-degree arrivals all had positive residual, median +0.0949mJ. Historical `SideEnergyFeedback` discards peaks below 6 degrees, so the startup data cannot update that residual. Adding only .05mJ to its 80ms prediction cannot change the recorded selections because the target exceeds the maximum prediction by at least .0516mJ. These are repeated observations in one trajectory, not a proof of intervention response.

A separate target-8 / positive branch-5 low-peak learner uses matched measured peak potential minus the uncorrected prediction; it does not modify the existing higher-angle side feedback. It requires three mutually consistent positive residuals, recent negative peak at least 3.2 degrees, fresh wheel and camera observations, observed left-camera excursion exceeding right, 400mA output, bounded rate, RPM and battery. The offset changes by at most .01mJ per matched peak and is capped at .12mJ. It is calculated against the existing bridge-corrected prediction, so the existing bias is not added twice. This is only an empirical peak-energy correction, not real total mechanical energy or a model of foot-ground contact.

When the ordinary selector already chose positive branch 5 and 400mA, the candidate search uses the same current and existing maximum cap, with a 60ms floor and width constrained to the previous command +/-5ms. Stop, invalid input, an existing tighter cap, a zero output, or an ordinary selector choosing 300/350mA takes priority. Missing observations unwind the offset. Two weak opposite peaks, excessive camera imbalance, or no measured camera-balance improvement after eight reduced-width cycles disables the learner and unwinds it; recovery to the ordinary width is likewise slew limited while a valid 400mA branch remains. This feedback is experimental, and camera error and body peak can drift for reasons unrelated to the small pulse change.

A static replay of the recorded states, ending before the first changed command, selects 78ms instead of the recorded 80ms at 12.304s with a bias of .08mJ. That replay cannot simulate subsequent changed dynamics. Physical yaw direction and actual straight travel remain unverified. The pre-existing two-peak MPC is bypassed while this separately constrained candidate is selected, so the two selectors cannot change the same action independently. The bounded correction does not prove that the next walk is straight, and active yaw feedback is still absent.
